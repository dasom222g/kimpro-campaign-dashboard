# 김 프로 캠페인 집행 대시보드

`index.html`을 브라우저로 열면 됩니다. 외부 연결 없이 사용하며, 기본은 다크 모드입니다.

공개 주소: https://dasom222g.github.io/kimpro-campaign-dashboard/

`main` 브랜치에 푸시하면 테스트·빌드를 거쳐 GitHub Pages에 자동 배포합니다. 배포 파일은 `index.html` 하나이며, 입력 CSV를 내장하고, 보고 양식과 보고서 PDF는 한글 글꼴을 포함해 브라우저에서 생성합니다. CSV는 Excel 한글 호환을 위해 UTF-8 BOM을 포함합니다.

## 시연 순서

| 순서 | 조작 | 확인할 결과 |
|---|---|---|
| 1 | `입력자료/01_매체별_집행내역.csv` 업로드 → 반영하기 | 36건 · 예산 2억 원 · 집행액 1억 470만 원 · 소진율 52.4% |
| 2 | 미집행 내역 탭 | 12건 · 캠페인·매체별 필터 가능 |
| 3 | 내역 한 건 수정 → 저장 → 되돌리기 | 금액과 소진율 변경·복구 |
| 4 | 브라우저 새로고침 또는 닫고 같은 주소로 다시 열기 | 내역 보존 · 필터 초기화 |
| 5 | `검증자료/02_금요일_갱신내역.csv` 업로드 → 반영하기 | 신규 1건·갱신 1건 → 37건 · 1억 710만 원 · 53.6% |
| 6 | 조회 내역 CSV / 전체 내역 CSV 내려받기 | 조회 조건과 무관하게 보관할 때는 전체 CSV |
| 7 | 보고서 다운로드 ↓ | 보고 양식에 조회 데이터를 채운 PDF 파일 다운로드 |
| 7-1 | 조회 내역 PDF ↓ | 기존 조회 화면 인쇄 · 인쇄 창에서 PDF로 저장 선택 |
| 8 | 전체 비우기 → 되돌리기 | 분기 정리·복구 |

샘플 불러오기 아래 **실습용 자료 · 김 프로 샘플 → 입력 데이터 CSV 다운로드**는 업로드 연습용 원본 CSV를 내려받습니다. 현재 저장 내역이나 필터와 무관하며, 다운로드만으로 데이터가 추가되지는 않습니다.

`김 프로 샘플 불러오기`는 1번 CSV와 같은 자료를 넣습니다. 업로드 후 변경 건수를 확인하고 반영합니다.

## 파일

- `00_구상메모.md`: 사용자가 제공한 구상메모 사본.
- `02_명세서.md`: 구현 기준과 검증할 완성 조건.
- `index.html`: 수강생에게 보여줄 단일 HTML 도구.
- `입력자료/01_매체별_집행내역.csv`: 도구에 업로드할 집행 내역.
- `입력자료/02_매체별_집행_보고양식.pdf`: 제작할 때 AI에게 전달할 보고 형식 참고자료. 도구 업로드 대상이 아니다.
- `검증자료/`: 동일 내용 XLSX·금요일 갱신 CSV.
- `검증결과/`: 화면 캡처·PDF·CSV·검증 기록.
- `src/`, `scripts/`, `tests/`, `vendor/`: 수정·빌드·검증용 소스.

## 데이터 기준

같은 캠페인의 총예산은 모든 행에서 같아야 하며, 요약에는 한 번만 합산합니다. 예산 요약은 선택한 캠페인의 전체 기간 기준, 아래 표와 매체별 조회는 필터 기준입니다.

CSV를 갱신할 때 `내역ID`를 유지하세요. 같은 ID는 갱신, 같은 값은 건너뜁니다. ID 없는 자료는 캠페인·매체·집행일이 같고 값도 같으면 중복입니다. 같은 날짜·매체의 서로 다른 건은 ID로 구분해야 합니다.

브라우저 데이터 삭제·다른 브라우저·다른 주소에서는 저장 내용을 그대로 사용할 수 없을 수 있으므로, 분기별 전체 CSV를 보관하세요. 전체 비우기는 최근 10회 변경 내에서 되돌릴 수 있습니다. 원본 입력 파일은 수정하지 않습니다.

실제 회사 양식 대신 김 프로 예시용 빈 PDF 보고 양식을 제공합니다. 예산 요약 → 매체별 집행액 → 집행 내역 → 미집행 목록 순서입니다. **보고 양식 PDF 다운로드**는 빈 양식, **보고서 다운로드 ↓**는 같은 양식에 조회 데이터를 채운 PDF를 내려받습니다. **조회 내역 PDF ↓**는 기존 조회 화면을 인쇄합니다. 세 기능은 구분됩니다. CSV 정리·신규 파일 업로드는 사용자가 수행하며 메일/폴더 자동 감시는 없습니다.

## 개발·검증

```sh
npm run samples
npm run build
npm run report-template
npm test
npm run test:browser
```

브라우저 검증은 Playwright와 Chrome이 있는 환경에서 실행합니다. Playwright가 별도 경로에 있으면 `PLAYWRIGHT_MODULE`로 지정합니다. 샘플 재생성 후에는 반드시 다시 빌드하세요.

PDF 생성은 jsPDF 4.2.1과 NanumGothic을 사용합니다. 한글 글꼴은 HTML 및 생성 PDF에 포함되며 외부 서버에 데이터를 보내지 않습니다. 원본 라이선스는 `vendor/`에 포함합니다.
